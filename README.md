# SQL Detective Challenge – The Miami Marina Murder 🕵️‍♂️

## Overview

This project is a fictional SQL detective challenge where the objective was to solve a murder case using structured datasets and SQL queries.

The investigation involved analyzing:

* Crime scene reports
* Interviews
* Hotel check-ins
* Surveillance records
* Confessions

Using SQL logic and relational querying, the suspect was identified step by step.

---

## SQL Concepts Practiced

* SELECT statements
* WHERE filtering
* LIKE and wildcard searches
* JOIN operations
* IN conditions
* Multi-table querying
* Logical deduction using relational data

---

## Investigation Process

### Step 1: Analyze the crime scene

Queried the `crime_scene` table to gather initial clues.

### Step 2: Identify witnesses

Used wildcard filtering on names and addresses to locate possible witnesses.

### Step 3: Read interview transcripts

Connected witness IDs with interview records to uncover new leads.

### Step 4: Investigate hotel check-ins

Filtered hotel records by date and hotel name patterns.

### Step 5: Connect surveillance activity

Used JOIN operations between `hotel_checkins` and `surveillance_records`.

### Step 6: Find the confession

Matched suspect IDs with confession records to identify the murderer.
